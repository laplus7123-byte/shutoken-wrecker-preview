# 房総レッカー版 LP

元LP（https://bousouwrecker.com/01/）をベースに、元の房総エリアの内容と構成を保った版です。

確認ページ: https://laplus7123-byte.github.io/shutoken-wrecker-preview/bousou/

反映した変更:
- 添付FVに差し替え。緑色の「房総レッカー」を維持し、画像内の「認定工場」を「認証工場」に修正。
- 本文と工場画像も「認証工場」に統一。
- 帰宅支援の説明を「レンタカー貸出・手配」に統一。
- 電話案内を「整備士直通」に修正。
- 390px幅、絵文字なし、見出しの中央揃え、FV直下の電話番号を大きく表示。

千葉・房総、木更津東IC付近という元の拠点情報・地図・バナーを使用しています。

## 使用方法
`index.html` と `assets` フォルダを同じ階層に置いてください。`index.html` をブラウザで開くと確認できます。
公開する場合はフォルダの中身を公開先にアップロードしてください。

広告計測は元の本番ドメイン `bousouwrecker.com` でのみ動作します。確認版は検索エンジンのインデックス対象外です。
